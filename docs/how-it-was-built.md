# How Lifeboard was built

Most of the code in this repo was written by Claude Code agents, a fair amount of it overnight, while I wrote the briefs and decided what got merged. The first version went in on 16 August 2026 and the rest landed over the following fortnight.

## Rounds, worktrees and hand-offs

Work ran in rounds. The first overnight round, on 17 August, was four agents running in parallel, each in its own git worktree on its own branch. `overnight/infra` owned `infrastructure/`; `overnight/sync` owned the storage, auth and sync modules plus the settings view; `overnight/pwa` owned `public/`, the Vite config and `index.html`; `overnight/ui` had everything else in `src/`.

That ownership table was the part I put the most thought into. Separate worktrees stop agents trampling each other's checkouts, but they don't stop two branches rewriting the same file, so who owned what had to be written down. The UI agent owned `App.tsx` that night, which meant the other three left their integration undone and wrote the exact wiring into their logs instead. I did it by hand at merge time, with ui last because it had the widest surface. No agent merged anything. A second round of four ran the same day off the merged branch, covering the calendar, user-defined categories, the completion model and the brain dump capture.

Every agent finished with a hand-off log, and those logs were what I actually reviewed. They followed a common shape: what was built, the decisions and the reasoning, what was verified and what wasn't, the wiring left for me, every edit to a file the agent didn't own, and a section along the lines of "where I think the brief is wrong or incomplete".

The gaps sections earned their keep. The infra log had a heading that read "Not verified, and you should assume it is wrong until it is not"; nothing had been planned or applied, and it named the one Cognito setting it thought most likely to block the first Google sign-in. The agent reworking the card interactions said it had driven a mouse, so the swipe gestures were untested, and that the weekend rule was covered by tests but never seen live because 17 August was a Monday. The brain dump log said the Lambda deployment package had never been built. It was right to; the first real build failed, with a module missing from the bundle and pip pointing at the wrong package index.

The flags were also where agents caught each other. The categories agent spotted that `mergeStates` in the sync module rebuilt state from only `version`, `items` and `goals`, so any sync would silently throw away a user's categories. It couldn't touch that file, so it made the new field optional and wrote the one-line fix into its log; `fix(sync): stop mergeStates dropping unrecognised state fields` went in the same day.

I didn't hand-review the UI line by line, and I didn't want the agents judging it from source either. The briefs asked for judgement from the running app at a 375x812 viewport, so the logs came with before and after screenshots in light and dark. Measurements turned out to matter more than pictures. The design pass claimed lane headings had 28px above them. The calendar agent, on a different branch, measured every heading on Today and Buy at `margin-top: 8px`: each heading sat in its own `<section>`, so `first:mt-2` in `Lane.tsx` matched all of them. It didn't own that file, so it reported the bug. The interactions agent confirmed it and fixed it with a `Lanes` container that owns the gap. I doubt I'd have caught that reading the diff, because the classes look right.

## Reviews, and what changed after use

Reviews ran as separate agents, each given the same shared context and a single lens. The first one, on the first version, used four: user, design, commercial and engineering. One lens per agent was deliberate, so the reviewers could disagree; in my experience a single agent holding every perspective drifts towards consensus. Each had to use the app, and was told to assume at least one of my design decisions was a mistake.

That review fed straight into the overnight briefs. It flagged as critical that the status button completed an item without undo while swipe-right came with it, and it found items that could end up in no lane at all. The interactions round made the box a plain checkbox with the undo toast, and added a folded Waiting row so nothing went unrouted.

Later rounds narrowed the lens to onboarding, then controls, then a functionality and UX polish pass driven with Playwright at 375 and 320 wide in both themes. That one ranked findings as Broken, Confusing, Rough or Nit, and marked each as verified in the browser or inferred from code. The fixes on 19 August read like its list, down to dismissing only the topmost overlay and committing goal edits per field.

The product calls stayed with me, and the logs marked where they sat. The interactions agent called the one-tap `Today` button on each card "a deliberately reversible call" and pointed at the one handler to swap if I kept reaching for a date picker instead. The Waiting row came with a note that deleting one entry would remove it if I disagreed. After using it on my own phone I changed the lanes, chips, dates and theme, and decided that Now means today, with overdue work leading it rather than sitting in its own lane.

Some predictions came true once I used it. The brain dump log said continuous recognition through a long pause was where it expected a rough edge; two later fixes kept the microphone on through a pause until I stop it, and kept only the newest interim result so dictation stopped repeating itself.

The one that could have hurt was Terraform. The infra agent had gitignored all tfvars, sensibly, because the Google client secret was an input at the time. Once the Google credentials moved to Parameter Store that reason went away, but the domain and Cognito settings still lived in a gitignored file on my laptop, and CI only set a couple of flags through `TF_VAR_` variables. CI's plan therefore fell back to the variable defaults: it would have destroyed the ACM certificate and the DNS records, and replaced the Cognito hosted UI domain, breaking the redirect URI registered with Google. The fix was to commit the non-secret configuration as `dev.auto.tfvars`, which Terraform loads automatically, so CI and a laptop apply the same thing and the secrets stay in Parameter Store.
